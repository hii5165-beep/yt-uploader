yt-uploader

yt-uploader is a private, personal desktop tool. Its only user is the owner of the YouTube channels it uploads to (contact: hii5165@gmail.com).

It uses the YouTube Data API v3 to upload videos the owner created to the owner's own YouTube channels, set their thumbnails, add them to playlists, upload caption files and check their processing status.

The tool is not offered, sold or distributed to anyone else.
